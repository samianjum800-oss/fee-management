# School settings and campuses

## Overview

Use **Settings** to update the school name shown in AXIS, upload a school logo, and change the administrator username or password. If your school uses the wing-school setup, this page also manages its campus and sub-wing names.

Settings are for the current school's portal only. They do not create a school account, enable new modules, or change another school's data.

## Update the school profile

1. Sign in as the school administrator and open **Settings** from the school menu (or **More** on mobile).
2. Edit **School Name** if it has changed.
3. To change the logo, choose **Upload Logo** and select an image from your device.
4. Review the current administrator username. Enter a new username only if you want to change it.
5. To change the password, fill both **New Password** and **Confirm Password** with the same new value. Leave both blank to keep the current password.
6. Select **Save All Changes**. Confirm the updated name/logo and use the new credentials the next time you sign in.

!!! warning "Keep the administrator account private"
    Give routine work to individual staff accounts. Do not send the school administrator password in a group chat or reuse it as a teacher's password.

## Add or rename a campus or wing

These controls appear for a school configured as a wing school. A campus can stand alone or have sub-wings beneath it.

1. On **Settings**, go to **Campuses and Wings** and choose **Add New**.
2. Enter the **Main Category** (for example, `North Campus`).
3. Optionally enter a **Sub Category** (for example, `Girls Wing`). Leave it blank if the campus has no sub-wing.
4. Choose **Add Category**.
5. To rename an item, choose **Edit** beside it, update the main name and/or sub-category, then choose **Update Category**.
6. Check class and student forms afterward so new records are assigned to the intended campus and wing.

```text
School settings
+ School Information: name, logo             [Save All Changes]
+ Account Security: admin username/password
+ Campuses and Wings
    North Campus (Girls Wing)                 [Edit]
    North Campus (Boys Wing)                  [Edit]
                                               [Add New]
```

!!! note "Existing records"
    Campus and wing names are used in class/student labels. Decide on a consistent naming pattern before creating many records. If a category is no longer needed, ask the AXIS administrator for help rather than creating a similarly named replacement.

## Desktop and mobile

=== "Desktop"

    The desktop settings page has school profile/security fields and, for wing schools, a **Campuses and Wings** section.

=== "Mobile"

    Open **More** and then **Settings**. Update the school name, logo, or administrator credentials. Campus/wing controls are available on the wing-school mobile settings page; use desktop if the smaller layout is difficult to review.

## Common scenarios

- **A new campus is opening:** Add the main campus and its sub-wings before adding classes for it.
- **The principal is changing:** Change the administrator username/password and share the new credentials securely with the incoming account owner.
- **The logo looks wrong:** Upload a supported image again, save, and refresh the portal. If no logo appears, ask the AXIS provider to check uploaded media access.

## FAQ

### Does changing the school name change the portal address?
No. The settings screen updates the displayed name; it does not change the school-specific portal link.

### Can I add campuses in every school setup?
The campus/wing editor is shown for wing schools. A single small school uses flat class names instead.

### Can I reset a teacher's password here?
No. Use **Staff Management**, open the staff member's profile, and reset that person's staff credentials. See [Classes and staff](classes-and-staff.md).

### Why can't I see a feature menu?
Feature availability is controlled by the school/AXIS setup, not by the profile settings page. Contact your AXIS provider or designated account administrator.

## Troubleshooting

| Problem | What to do |
|---|---|
| Password fields show an error | Re-enter the same value in both password boxes. If you are not changing the password, leave both blank. |
| Logo does not change | Confirm you selected the file, save the page, and refresh. If it still does not appear, ask support to check file upload access. |
| A campus/wing name is rejected | Check for an existing category with the same name under that main campus. Keep names unique and simple. |
| You cannot access Settings | Confirm you are signed in to the correct school administrator account and that the settings feature is enabled. |
